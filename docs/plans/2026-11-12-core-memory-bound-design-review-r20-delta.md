3. should Decision 1 broadcast rings, release column (design.md:303), r19 #2: the Released column lists three triggers for one charge: last ring slot overwritten, receivers drop, and a drop guard on last Arc drop. The drop guard is also undefined: no wrapper type, location, or effect on the public type is named. `Arc<Event>` is public (store.rs:194, :1165; websocket.rs:77, :88-94). Cited line numbers were not verified because fetched excerpts had none. Fix: one release rule, last Arc drop. Delete "overwritten" and "receivers drop" from the Released column. Name the wrapper type and file, and state its effect on `Receiver<Arc<Event>>` (store.rs:1165, websocket.rs:94), or keep `Arc<Event>` by putting the guard inside `Event`.
