# Public SEO remediation autoresearch

## Job

Resolve every code-addressable finding from the 27 August 2026 Codex SEO audit without weakening AllSource product accuracy, public navigation, or performance. External authority, customer proof, search-engine recrawl, and field Core Web Vitals remain evidence gates rather than claims code can manufacture.

## Chosen approach

Work by shared failure mode, then route-specific depth: metadata and index policy; broken paths and sitemap truth; mobile rendering and accessibility; entity/schema consistency; product-intent pages; citations and internal links. This fixes root causes before adding pages.

Rejected approaches:

- Rewrite every route independently: high drift and repeated defects.
- Publish content first: leaves wrong canonicals and broken links active.
- Chase one composite SEO score: hides regressions in accessibility, accuracy, or bundle weight.

## Design direction

Preserve AllSource midnight/cyan system. Product-specific signature remains executable event path: write → inspect → query → replay. Query Service gets distinct realtime, analytics, HTTP, and projection read lanes. Motion explains state only; no entrance motion for LCP content. Conversion surfaces never sit under fixed controls.

## Frozen autoresearch rubric

| Signal | Weight |
| --- | ---: |
| Index policy, canonicals, sitemap, and internal links | 20 |
| Product/entity accuracy and primary-source evidence | 15 |
| Query intent and self-contained answers | 15 |
| Mobile LCP/CLS and route weight | 15 |
| WCAG AA contrast, focus, and 48px targets | 15 |
| Schema validity and page-type fit | 10 |
| Navigation and contextual internal links | 10 |

Baseline: 81/100 SEO health. Keep correctness fixes regardless of small byte cost. Discard decorative changes with no rubric gain. Stop after all code-addressable audit items pass or three consecutive experiments fail.

## Verification

- production web build and type checks
- deterministic public-route crawl
- 3-run mobile Lighthouse on homepage and new pillars
- ProofShot desktop, tablet, and mobile navigation/CTA checks
- structured-data parse and canonical assertions
- route-weight comparison
