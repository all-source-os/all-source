Event Schema Evolution Without Rewriting History

Compatible order event evolution

v1 order.placed { "total_pence": 14999, "contract_version": "uk-1" }
v2 order.placed { "total_pence": 14999, "currency": "GBP" }

read v1 -> resolve uk-1 against retained immutable contract evidence
if contract evidence is missing -> mark currency unknown; do not guess
read v2 -> use explicit currency
stored v1 payload remains unchanged

The contract identifier and values are illustrative; they do not establish an AllSource API field or contract lookup capability.
