## Tagline

## Overview

AllSource builds developer infrastructure for durable event history and
evidence-backed AI-agent memory.

AllSource Core is a Rust event store. It records changes as immutable events,
derives current state through projections, and supports replay and point-in-time
queries. Prime adds graph, vector and temporal memory for AI agents. Hosted
AllSource provides managed access, with MCP connectors for compatible tools.

Use AllSource to reconstruct application state, investigate changes and preserve
agent context across sessions. Public source, documentation and runnable
benchmarks explain the capabilities and their limits.
