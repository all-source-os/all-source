# Allstack catalog

Read repository instructions and the [installed catalog guide](../../../docs/reference/allstack-catalog.md). Use `allstack catalog` and `allstack catalog <id>` to inspect versioned workflow data before choosing a workflow. Use `start --workflow delivery|bugfix` only on an already authorized live feature branch, with an indexed request and explicit verification policy. Commit and publication flags require trusted user authority.

For bug fixes, include reproduction inputs, retained failure output, expected behavior, and regression acceptance in the request. Treat unproven causes as unresolved. Diagnose the responsible data contract or producer before changing generic mechanics. The selected plan and build methods supply workflow-specific instructions.

Continue through the [CLI and recovery guide](../../../docs/reference/allstack.md). Read `status` and `resume` before acting; use the current epoch and active detached worktree. AllSource retains selected workflow and methods, the coordinator owns Chronis claims, and Prime recall requires source inspection. Use managed handoff, verification, and shipping. Do not create branches, commit, publish, change claims, or bypass permissions inside a managed host call.
